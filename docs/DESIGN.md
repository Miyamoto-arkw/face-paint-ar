# Face Paint AR 設計

## 目的

スマホのブラウザでカメラを起動し、管理画面から登録した透過PNGの絵柄を顔に貼り付けて、フェイスペイントを疑似体験できるようにする。

## 方式：固定UVテクスチャマッピング

MediaPipe の正準顔モデル（`canonical_face_model.obj`）では、468個のランドマークそれぞれに固定のテクスチャ座標（UV）が決まっている。

- テクスチャ（1024×1024の展開図）上に絵柄を描く
- 毎フレーム、顔メッシュの三角形ごとに「テクスチャ上の三角形 → 画面上の三角形」をアフィン変換で描く

UVは顔の向き・大きさ・人によらず不変なので、絵柄は皮膚に張り付いたまま回転・傾きに追従する。
「どこに描くか」はテクスチャ上の位置で決まるため、ランドマーク番号の集合を手で調整する必要がない。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `lib/faceModel.ts` | 自動生成。468点のUV、898三角形、UV空間の縦横比補正値 |
| `lib/extendedMesh.ts` | 顔メッシュの外周を外側へ1周延長（額は生え際付近まで、横・下は少しだけ） |
| `lib/regions.ts` | 配置範囲（UV上の多角形）、テクスチャ生成、管理画面用テンプレート描画 |
| `lib/faceTracker.ts` | MediaPipe 初期化（GPU→CPUフォールバック）、ランドマークのスムージング |
| `lib/renderer.ts` | 三角形ごとのアフィンワープ描画 |
| `components/FaceCanvas.tsx` | カメラ起動、描画ループ、合成 |
| `app/debug/page.tsx` | 開発専用。顔写真に同じパイプラインを当てて確認する（`public/debug-face.jpg` が必要） |

## 描画パイプライン

1. 絵柄の選択時・左右の切替時に1回だけ：テクスチャを作り、絵柄に掛かる三角形だけを選んでおく（頬・目尻なら約40枚、全顔なら898枚）
2. 毎フレーム：
   - 新しいビデオフレームのときだけ顔を検出し、適応型スムージングを掛ける
   - オフスクリーンのレイヤーにワープ描画する（継ぎ目が出ないよう、各三角形を0.75px広げてクリップする）
   - カメラ映像の上にレイヤーを1回だけ合成する（乗算または通常）
3. 座標計算はカメラ画像のまま行い、表示だけCSSで鏡にする

## 配置プリセット

`lib/regions.ts` の `LEFT_SIDE_REGIONS`（ユーザーの左側、UV座標の多角形）。絵柄は多角形の外接矩形に収めて置き、多角形の外は切り抜く。右側は u=0.5 で鏡像にする。

- 頬：目の下〜口角の少し下、鼻翼の横〜フェイスライン
- 目尻〜こめかみ：目尻を頂点にした扇形。上は眉の上を通って額の中央・生え際付近まで、下は目尻の下の頬まで（目と眉の内側は除く）

位置を調整するときは、この座標だけを変えればよい。`/admin` からダウンロードできるテンプレートに、配置枠が描かれている。

制約：MediaPipe の顔メッシュは額の途中までしかないため、外周を延長して生え際付近まで描けるようにしている（`lib/extendedMesh.ts` の `EXTEND_UP`）。横方向は大きく延ばすと背景に絵柄が浮くので、ほとんど延ばしていない。そのため耳の上には描けない。

## 左右と向き

- 「左／右」は、ユーザー自身から見た左右。鏡表示なので、左頬は画面の左側に映る
- 絵柄は「左側に置いたときに画面上で描いたとおりに見える向き」で作る。右側には左右反転して配置される
- 全顔はテンプレート（画面上の見え方と同じ向き）に合わせて描く

## 静的アセット

- `public/mediapipe/models/face_landmarker.task`：コミット済み
- `public/mediapipe/wasm/`：`postinstall`／`prebuild` で `node_modules` からコピーする（JSとwasmのバージョンを必ず一致させるため）

## 再生成

`lib/faceModel.ts` は、MediaPipe リポジトリの `mediapipe/modules/face_geometry/data/canonical_face_model.obj` から生成する。OBJ の `vt` は下が0なので、v = 1 − vt で上を0に変換する。
